# COVID-19 Professional Analytics Platform

A comprehensive, professional-grade analytics dashboard for COVID-19 data visualization and insights. This platform transforms complex pandemic data into actionable insights through cutting-edge visualization and analysis.

### 🔧 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd covid-visual-analytics/frontend
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm start
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
